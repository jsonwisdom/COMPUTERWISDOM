# Computer Wisdom — CI-FIRST Live Builder v0.4

## Mission
Discover → Imagine → Create → Test → Review → Improve. CI-FIRST is an active engineering process, not an indefinite evidence HOLD. Historical receipts are inputs to building, not prerequisites to repeat.

## Participation
Everyone, including women and girls, can learn, propose ideas, contribute code, document research, and participate in civic oversight without a wallet, token purchase, or payment. Provide age-appropriate learning routes and privacy protections for minors; do not publish minors' personal data or imply consent on their behalf.

## Operating lanes
- DISCOVER: inventory existing repos, open PRs, workflows, issues, sites, and project trees; link exact sources.
- CREATE: branch, implement, test, document, and propose PRs using least privilege.
- VERIFY: run CI, deterministic tests, accessibility checks, and provenance checks; distinguish tested from proposed.
- PROMOTE: human approval for protected-branch merges, public production deployment, signing, spending, or governance authority changes.
