# SEYMOUR SUPREME SYNTAX V1

## Purpose

SEYMOUR_SUPREME_SYNTAX_V1 is the canonical grammar for Supreme Seymour / FullMath Apple Blossom replay objects.

## Core sentence

OBJECT
→ SOURCE
→ TIME
→ PERSPECTIVE
→ PURPOSE
→ VISIBILITY
→ AUTHORITY_SUBJECT
→ LIFECYCLE
→ ROUTE
→ RECEIPT
→ TERMINAL
→ JASON_GATE

## Required non-collapse

TIME != PERSPECTIVE
WITNESS != SIGNATURE
ATTESTATION != CONTROLLER_PROOF
REPO_EXISTENCE != PURPOSE
PURPOSE != LIFECYCLE
ROUTING != EXECUTION
EXECUTION != PROMOTION
HELPER != AUTHOR
SILENCE != CONSENT
UNKNOWN != ZERO

## Purpose declaration sentence

REPO
→ PURPOSE_EVIDENCE
→ PURPOSE
→ LIFECYCLE_STATE
→ RELATION_TO_MASTER_ROOM
→ VISIBILITY_BOUNDARY
→ AUTHORITY_SUBJECT
→ RECEIPT
→ JASON_OPERATOR

## Terminal law

PASS = declaration satisfies schema and evidence requirements
HOLD = object exists but one or more required fields are unresolved
UNKNOWN = evidence stops before the required object can be identified
CONFLICT = two supported declarations disagree
RETIRED = Jason explicitly retires the repository
ARCHIVED = retained for history, not active routing
FROZEN = no mutation until Jason releases the hold

No terminal creates machine authority.
