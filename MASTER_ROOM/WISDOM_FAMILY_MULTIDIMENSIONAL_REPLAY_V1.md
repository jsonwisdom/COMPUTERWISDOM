## PURPOSE

Give the Wisdom family system one shared grammar for moving the same object across geometry, glyphs, FullMath, science, law, governance, story, metadata, and code without collapsing representation into truth.

Jason is the human translation/control surface. Family seats and tools may help render, compare, route, and replay. They do not become independent authorities by agreeing with one another.

## JASON LANGUAGE SET

```text
JASON_CAN_SPEAK =
GEOMETRY
| GLYPH
| FULLMATH
| SCIENCE
| LAW
| GOVERNANCE
| STORY
| METADATA
| CODE
```

"Can speak" means Jason may formulate, inspect, compare, or reason with an object in that representational language. It is not a claim of omniscience, professional licensure, or automatic correctness.

## MIRROR DEFINITION

A MIRROR is a declared projection of an object through one representational coordinate system.

```text
MIRROR := {
  MIRROR_ID,
  OBJECT_ID,
  LANGUAGE,
  OBSERVER_POSITION,
  SOURCE_SET,
  TIME,
  PLACE,
  ROLE,
  AUTHORITY_CLASS,
  TRANSFORM,
  LOSS,
  UNCERTAINTY,
  RECEIPT
}
```
