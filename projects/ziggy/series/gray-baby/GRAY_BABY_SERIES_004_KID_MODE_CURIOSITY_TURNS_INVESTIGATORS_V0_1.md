## Core principle

> **Curiosity turns kids into investigators when questions become replayable evidence trails.**

Kid Mode does not begin with suspicion. It begins with a child noticing something and asking how to check it.

```text
CURIOSITY
-> OBSERVATION
-> QUESTION
-> SOURCE
-> RECEIPT
-> ENVIRONMENT
-> FIRST GAP
-> REPLAY
-> PARENT-SAFE FINDING
```

## Six-year-old investigation loop

1. What did I actually see, hear, read, count, or measure?
2. What am I guessing?
3. Who said it?
4. What environment was this happening inside?
5. Where is the receipt?
6. What is the first thing we still do not know?
7. Can someone else replay the trail?

## Boundary rules

```text
CURIOSITY != ACCUSATION
QUESTION != GUILT
SOURCE_IDENTITY != CLAIM_PROOF
OFFICIAL_LOOKING != OFFICIAL
RECEIPT != TRUTH
HASH != TRUTH
INVESTIGATOR != ENFORCER
HOLD != FAILURE
UNKNOWN_HOLD = SUCCESSFUL_GAP_DETECTION
```

The child gains a method, not institutional authority.

Kid Mode does not require private student records, covert surveillance, confrontation, public accusation, or publication. Parent / guardian remains the boundary authority for participation and sharing.

## Environment-aware investigation

Every question lives inside boundary conditions:

```text
(S_n, E_n) --I_n--> (S_(n+1), E_(n+1))
```

Kid Mode therefore asks not only **what happened?** but also:

> **What environment had to exist for this claimed transition to occur?**

Relevant environmental lanes may include physical, legal, institutional, network, economic, social, temporal, jurisdictional, resources, active rules, incentives, and constraints.

## Success condition

Kid Mode is successful when the child can stop at the first unresolved edge without inventing an answer.

```text
MISSION_SUCCESS = QUESTION_REPLAYED_TO_FIRST_GAP
MISSION_SUCCESS != CLAIM_PROVEN
```
