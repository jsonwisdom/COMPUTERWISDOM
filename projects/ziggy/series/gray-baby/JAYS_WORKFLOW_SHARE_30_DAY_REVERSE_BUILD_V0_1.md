# Jay's Workflow Share — Gray Baby × Ziggy

## 30-Day Reverse Build v0.1

Status: `OPEN / DRAFT / HUMAN-GATED`  
Authority created: `FALSE`  
Watch mode: `OFF`  
Audit live: `TRUE`

## Purpose

Create one repeatable path for turning Jay's live research into a replayable artifact that can be shared with family, community, GitHub, Drive, PDF, or Facebook without silently promoting claims to truth.

## Core flow

```text
WORKING NOTE
  → ZIGGY NAVIGATION
  → LEAHPRIME CLASSIFICATION
  → GRAY BABY GAP + ANOMALY CHECK
  → SOURCE / RECEIPT CHECK
  → PARENT-SAFE / PUBLIC-SAFE REVIEW
  → SURFACE CHOICE
  → SHARE OR HOLD
  → REPLAY
```

## Reverse-build rule

```text
DAY 30 ← DAY 29 ← ... ← DAY 01
```

Each day starts from the final visible claim or artifact and walks backward:

```text
FINAL CLAIM
  → RECEIPT
  → SOURCE
  → ACTION / EVENT
  → ORIGINAL RECORD
  → FIRST GAP
  → ORIGINAL QUESTION
```

## Share states

- `PRIVATE_WORKING` — not ready to distribute.
- `PARENT_SAFE` — readable by family / guardian without inheriting accusation.
- `PUBLIC_SAFE` — source-linked, privacy-checked, lane-labeled.
- `SHARE_READY` — human has reviewed the exact artifact and audience.
- `HOLD` — missing source, unresolved privacy issue, unclear authority, or unresolved anomaly.

## Surfaces

- GitHub = canonical Markdown + append-only receipts.
- Google Drive = readable working / parent-safe mirror.
- PDF = frozen portable snapshot.
- Facebook = optional distribution surface only.
