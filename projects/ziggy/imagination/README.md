# Ziggy Imagination Sandbox

Imagination is where Ziggy may explore possibilities without rewriting preserved reality.

## Sandbox rule

`PROMPT → CANDIDATE → SANDBOX RECEIPT → HUMAN REVIEW`

Sandbox output may include draft code, stories, UI concepts, manifests, test vectors, or proposed GitHub changes.

It may not silently become:

- a BoxD original
- verified family history
- a merged release
- an ENS ownership claim
- a wallet authorization
- an on-chain attestation

## Promotion path

`IMAGINED → REVIEWED → PROPOSED_PR → VERIFIED → MERGED`

Every promotion step must preserve the candidate's origin and the human decision that moved it forward.

## Isolation

Candidate artifacts belong in sandbox-specific paths or branches until promotion. Existing preserved originals remain unchanged.

`IMAGINED ≠ VERIFIED`
