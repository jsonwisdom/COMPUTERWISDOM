# JASON progress: why the provenance bridge exists

**Scope:** evidence packet for a **draft, synthetic, private-only candidate** pipeline. This is not an import of Jason's originals, proof of past personal learning, or promotion of source claims to fact.

## Purpose first

- JASON is the denominator: the human's original purpose, source memory, chronological research, and corrections.
- JSON Wisdom/CWaaS seeks reproducible evidence rather than isolated confident AI narratives.
- The source-provenance bridge is intended to address a concrete failure mode: loss of original context and repetition of unresolved HOLDs without source-specific next tests.
- BNS (Gen Z and Beyond: conversation and purpose) is above ENS, Basename, DNS, and wallet/chain resolvers. A routing/name record never proves personhood or original source authorship.
- Automatic audits have PASS / FAIL / UNKNOWN verdicts derived from evidence. HOLD is a **dependent workflow gate**, never a verdict. Human authorization of external consequential actions is separate.

## Preserved stages, no fake green

| Layer | Candidate result | Strict boundary |
| --- | --- | --- |
| ORIGINAL | Private bytes read from confined local path, SHA-256 recomputed | A digest match is not source authenticity or authorship |
| PARSED | UTF-8 text or JSON syntactically readable under prior six-state intake | Parsed is not a validated CEO object |
| CEO (candidate) | Exact UTF-8 source byte offsets, excerpt, span hash, parser version, reported event-time | Excerpt attribution != truth; timestamp is DECLARED_UNVERIFIED |
| GRAPH (candidate) | Typed `EXACT_BYTE_SPAN_OF` source edge, raw source digest | No family, human identity or implicit authority relation |
| FOLD (candidate) | Stable, append-only observation IDs; distinct interpretations preserved | Contradictions are conflict **candidates**, never silently replaced |
| QUERY (candidate) | Observation IDs, conflict warnings, relevant unavailable source warnings | Claim verdict UNKNOWN; reconstruction completeness UNKNOWN |
| RECOVERY | Scoped reason plus explicit next action | Other supported paths continue |

## Temporal and disappearance boundary

The earliest JASON_OS prototype was frozen as CEO → GRAPH → FOLD → QUERY but full source ingestion was blocked on original export bytes. The present bridge does **not** claim that full ingestion occurred. An optional previous private candidate report can be replayed, preserving old observations if current source files vanish. Former observations get `SOURCE_UNAVAILABLE_PRIOR_OBSERVATION_RETAINED` warnings rather than unearned green. Repeated ingestion of identical annotations is idempotent.

## Private/public boundary

The candidate bridge only runs when **JASON_SOURCE_MANIFEST** and **JASON_CLAIMS_MANIFEST** are supplied in the local environment. The detailed report stays in `build/supreme-seymour-flywheel/private/ceo-graph-fold-query-candidate.json`, which is excluded from the existing GitHub artifact upload list. The public flywheel only receives counts and generic state categories. A malicious or malformed local manifest causes a scoped input-error result; it does not stop independent read-only public GitHub observations.

Do not commit originals, raw chat exports, private manifests, content excerpts, or private candidate reports to public GitHub.
