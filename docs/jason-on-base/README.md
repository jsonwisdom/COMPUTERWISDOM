## Film experience: "I DIDN'T KNOW"

1. Choose an official source link or local film with viewing permission.
2. Watch on your device, or open the source on a TV or other device.
3. One accessible button **I DIDN'T KNOW** records a local user reflection, optional note, scene label, client UTC time, and optional video playback position.
4. The local film player can record `currentTime`; it uploads no file and records no filename. Unknown local files are labeled **USER_SUPPLIED_UNVERIFIED**, not attributed to museum sources.
5. The page keeps response records in ephemeral JavaScript memory: no server requests for events, no localStorage/cookies, no telemetry. Reloading clears the list. **Export my JSON** creates a user-initiated file and **Erase this session** clears the current list. Downloads may remain on a user's device after page clearing.
6. No audience discovery. A future voluntary cohort requires review of consent, aggregation, re-identification, deletion, minors, accessibility and security before any live shared result. Neither geolocation nor Bluetooth proximity is requested.

## Everyone gets a Librarian Bot

The **Librarian Bot** is a retrieval and context explanation service, not a literal replacement for DNS. DNS resolves hostnames. The librarian organizes source indexes and search results, checks dated versions and claim scopes, preserves conflicts and gaps, and can produce a dated **daily public learning brief**.

Minimum behavior:

- Accept a human research question.
- Search an explicit source registry, attach title, issuing organization, canonical URL, publication or capture time, license if needed, and exact claim scope.
- State separate `OBSERVED`, `REPORTED`, `INFERRED`, `CONFLICT`, `HOLD` classes.
- Maintain source history so later revisions don't silently overwrite the questioner's original context.
- Offer three views: **Boomer Simple**, **8-Bit Arcade**, **FullMath Evidence**.
- Publish no private finance data, family's private stories, or user reflections.
- A daily brief can be generated only from actual ingested, verified sources. The current static sample **does not represent a live America-wide news feed**, real-time verification, or comprehensive coverage.
- DNS and trusted network security remain infrastructure underneath. Content provenance ≠ network provenance and neither grants government authority.
