## Source-node classes

The Saint Cloud map defines **classes**, not pre-verified facts:

```text
SC_AGENDA_NODE
  public meeting agenda / packet objects

SC_BUDGET_NODE
  adopted budget / financial document objects

SC_POLICY_NODE
  ordinance / policy / administrative document objects

SC_PUBLIC_NOTICE_NODE
  dated public-notice objects

SC_CIVIC_CLAIM_NODE
  public claim requiring comparison against preserved sources

SC_ARCHIVE_NODE
  superseded or historical public source versions
```

A class is not evidence by itself.

```text
NODE_DEFINED != SOURCE_PRESENT
SOURCE_PRESENT != SOURCE_VERIFIED
SOURCE_VERIFIED != CLAIM_TRUE
CLAIM_TRUE != AUTHORITY
```
