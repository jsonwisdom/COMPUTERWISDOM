# Wallet Purpose Chain

Status: design document. Not a transfer record. Not a control proof.

Append-forward is not overwrite. Append-forward adds context, receipts, and capacity. Earlier paths stay.

## Chain

Human, then purpose, then wallet role, then capital action, then receipt, then outcome, then next decision, then goal.

An address is not a role. A role is not a transfer. A transfer is not an outcome.

## Example roles

These names are not bound to slot 001 or the Base public anchor.

| Role | Purpose |
| --- | --- |
| Treasury | Protect liquidity |
| Active | Deploy a capped portion |
| Yield | Seek a recurring return |
| Exit | Realize a gain or reduce risk |

A later branch may point the same treasury role toward a home goal, a business goal, an investment goal, a family goal, or an emergency reserve. The new branch does not erase the old one.

## Edge receipt

Each movement, if one is later bound, needs its own edge:

- Why the funds moved
- Source
- Destination
- Asset
- Amount
- Date
- Thesis
- Risk
- Expected result
- Actual result
- Evidence

A missing field leaves the edge incomplete. Missing basis is not zero. Expected result is not actual result. A transfer is not a sale until the swap event is decoded.

## Loop

Purpose feeds inputs. Inputs feed signals. Signals feed a decision. A decision may become a wallet action. The action needs a receipt. The receipt supports an outcome. The outcome feeds learning. Learning returns to purpose.
