## Purpose

This artifact turns the project label **“NATO DICE OP substantial submarines and subsequent substrate substructures Onion Sacks TallinnTorTorrents”** into a safe, replayable public-source architecture.

The labels are metaphorical / architectural unless independently bound to a public factual source.

- **NATO DICE OP** = randomized audit-door ordering for NATO-related public-source claims. Dice never choose truth, guilt, authority, targeting, or action.
- **SUBSTANTIAL SUBMARINES** = metaphor for deeply submerged dependencies, assumptions, and unobserved layers. It is not submarine doctrine, patrol analysis, platform capability analysis, deployment analysis, or targeting.
- **SUBSEQUENT SUBSTRATE SUBSTRUCTURES** = dependency graph below a public claim: source → authority → implementation → infrastructure → oversight.
- **ONION SACKS** = compartmented evidence bundles. Each compartment carries its own receipts and HOLD state.
- **TALLINN** = public cyber-law / cyber-policy / doctrine-context lane, kept separate from NATO operational authority.
- **TOR** = privacy-network/public-documentation provenance label only. No evasion, anonymity tradecraft, intrusion, routing exploitation, or operational use is described here.
- **TORRENTS** = distributed-file provenance / version-drift metaphor only: object identity, hashes, source plurality, and replay. No piracy, unauthorized distribution, or evasion guidance is provided.
