## The Three-Card-Monte test

The satire label refers to proposition movement, not a finding of fraud:

```text
CARD 1: RECORD
What did the original record actually say?

CARD 2: CUSTODY
Who had the record, under what jurisdiction, at what time?

CARD 3: CHARACTERIZATION
How did the later office describe the same subject?
```

Run both directions:

```text
FORWARD
ORIGINAL EVENT / RECORD
→ CUSTODIAN
→ JURISDICTION
→ LEGAL RULE
→ DECISION
→ LATER RELEASE
→ PUBLIC CHARACTERIZATION

REVERSE
PUBLIC CHARACTERIZATION
→ RELEASE SET
→ REVIEW PROTOCOL
→ SOURCE CASE
→ ORIGINAL RECORD
→ ORIGINAL DATE
```

If the two directions land on the same receipt, bind the edge. If they do not, write `HOLD` or `CONFLICT`; do not infer motive.
