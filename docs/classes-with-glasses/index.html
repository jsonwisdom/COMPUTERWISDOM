⏱️ Jurisdictional Clock — six clocks, not one

A record can carry EVENT_TIME, DOCUMENT_TIME, EFFECTIVE_TIME, PUBLICATION_TIME, UPDATE_TIME, and RETRIEVAL_TIME. These are not interchangeable.

Every alleged mismatch needs a named actor, exact source, clock type, jurisdiction, and authorization before promotion. A current browser timestamp alone proves none of those historical events.

Retrieval timestamp is recorded only when you press the button.

🔁 Oodle Loop — receipts, not rumors

Customer service → request or recording notice → lawful source → exact account-safe transaction ID → dispute status → response receipt → correction/replay.

Travel, relatives, personal relationships, voter records or Delaware registration alone prove no wrongdoing. Never publish card numbers, secret recordings, private voter data, or nonpublic relatives' details.

Public research links: SBA PPP program; USAspending; Delaware corporate search.

Evidence classes: PASS for narrow sourced facts; HOLD for missing bank/payment evidence; CONFLICT for comparable valid records that disagree.
