## Functional metaphor

Computer Wizard holds the spinning flywheel.

A human question becomes a typed query object. The Wizard casts that query outward like a net across permitted public tools, COMPUTERWISDOM, School of Wisdom, and connected evidence rails. Returned observations stay "spinning" until the alignment gates pass.

```text
QUESTION
  -> QUERY_OBJECT
  -> COMPUTER_WIZARD
  -> CAST_NET
  -> PUBLIC_TOOLS / COMPUTERWISDOM / SCHOOL_OF_WISDOM / CONNECTORS
  -> OBSERVATIONS_SPIN
  -> ALIGNMENT_GATE
       PASS -> CAPTURE
       HOLD -> KEEP_SPINNING / REFINE_QUERY
  -> COMPUTERWISDOM RECEIPT
  -> SCHOOL_OF_WISDOM UPDATE
  -> PUBLIC 200 OK PAGE
  -> UPDATE BEACON
  -> JASON REVIEWS
  -> NEXT QUESTION
```

## Alignment gates

A returned object lines up only when its type, source, time, object identity, and evidence status are explicit enough for the task.

```text
MATCH != TRUTH
QUERY_HIT != VERIFIED
MIRROR != CORROBORATION
MISSING != ZERO
HOLD != FALSE
```
