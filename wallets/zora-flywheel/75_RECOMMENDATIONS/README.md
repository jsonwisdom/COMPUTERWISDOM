# FAMILY + BOT RECOMMENDATIONS

Recommendations are outputs, not commands.

Every recommendation should state the evidence used, unresolved HOLD items, expected upside, expected cost/risk, whether money/signing is involved, and who should review it.

```text
RECOMMENDATION != FACT
RECOMMENDATION != TRADE
RECOMMENDATION != FAMILY_CONSENT
RECOMMENDATION != HUMAN_DECISION
```

The public School of Wisdom page may show non-sensitive recommendations. Private financial evidence remains behind the connector membrane.
