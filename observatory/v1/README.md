# BUILD 017.3 — offline staging candidate
Run `python -m pip install -r requirements.txt` then `python -m unittest discover -s tests -v` from this directory.
Validate a staged dataset with `python verify.py DATA_DIRECTORY --anchor-sha256 INDEPENDENTLY_PINNED_SHA256`.
The dataset contains findings.json, receipts.json, anchor.json, corrections.json, remedies.json, baseline/{corrections,remedies}.json and evidence/<sha256> files. Receipt artifacts are relative to the dataset root. Anchor binds receipt registry and prior history digests and source commit. See tests for exact fixture format. Do not derive the trusted anchor from an untrusted dataset at validation time.
Canonical encoding is this implementation's sorted compact UTF-8 JSON, not RFC 8785. No live source fetching, signature verification, independent mathematical execution, timestamp freshness policy, or revision-chain verification is implemented. Revisions above one fail closed. Receipts are trusted assertions bound by the external anchor; fixture PASS is not independent evidence. Publication must remain HOLD. No GREEN lane derivation or human authorization flow implemented. Historical prefix comparison protects only the independently pinned baseline; newly appended history must be pinned before the next cycle. Dependency range is not a reproducible lockfile.
