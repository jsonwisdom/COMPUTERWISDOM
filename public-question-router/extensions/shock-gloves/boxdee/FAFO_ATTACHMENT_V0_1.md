# BoxD FAFO Attachment v0.1

Status: DRAFT / NON-RETALIATORY ACCOUNTABILITY LAYER / UNMERGED

```text
FAFO = FOLLOW AUTHORITY, FOLLOW OUTCOMES
FAFO != RETALIATION
FAFO != THREAT
FAFO != PUNISHMENT
FAFO != PHYSICAL ENFORCEMENT
```

## Purpose

Attach a consequences-and-receipts replay to every BoxD institutional question.

The attachment asks what happened after an institution exercised authority, spent money, withheld a record, filed a position, issued an order, corrected an error, or failed to respond.

## FAFO chain

```text
CLAIMED AUTHORITY
→ SPECIFIC ACTION
→ IMPLEMENTATION
→ HUMAN / SYSTEM CONSEQUENCE
→ NOTICE
→ REVIEW
→ CORRECTION / NO CORRECTION
→ COST
→ PUBLIC STATUS
→ VERSION DELTA
→ RECEIPT
```

## Four-Onion binding

```text
O1 RECORD      → WHAT CONSEQUENCE IS ACTUALLY OBSERVED?
O2 AUTHORITY   → WHAT POWER AUTHORIZED THE ACTION?
O3 EXECUTION   → WHO / WHAT IMPLEMENTED IT AND WITH WHAT RESOURCES?
O4 OVERSIGHT   → WHO REVIEWED OR CORRECTED THE RESULT?
```

FAFO cannot promote unless all relevant onions and joins are source-bound.

## Outcomes

```text
FAFO_PASS
Action, authority, execution, consequence, and correction path align.

FAFO_HOLD
A required consequence or authority edge is missing.

FAFO_CONFLICT
Observed outcome materially conflicts with the stated purpose, authority, policy, or correction record.

FAFO_REJECT
The scoped claim is contradicted by source-bound evidence.
```

## Institutional rule

```text
INTENDED_EFFECT != OBSERVED_EFFECT
POLICY_PURPOSE != IMPLEMENTATION
CORRECTION_PROMISED != CORRECTION_COMPLETED
BUDGET_AUTHORITY != RESULT
NO_RESPONSE_OBSERVED != GUILT
```

## Public attachment

Every public BoxD card may display:

```text
WHAT THEY SAID
WHAT THEY WERE ALLOWED TO DO
WHAT THEY ACTUALLY DID
WHAT IT COST
WHAT HAPPENED NEXT
WHO REVIEWED IT
WHAT CHANGED
WHAT REMAINS OPEN
```

## Core rule

**No revenge. No coercion. Follow the authority. Follow the money. Follow the outcome. Preserve the receipt.**
