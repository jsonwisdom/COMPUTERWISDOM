# COMPUTERWISDOM Asset Migration Planner v0.2

Status: `PLAN_ONLY`

Consumes Asset Inventory v0.3 and binds each buried candidate to its tracked Git blob SHA before suggesting a canonical repository surface.

Capability roles do not compete with artifact classes for storage location. An executable with an instrument role may receive a companion `instruments/*.md` contract while its runnable surface is proposed under `executables/`.

Suggested target paths preserve source-domain context to reduce basename collisions.
