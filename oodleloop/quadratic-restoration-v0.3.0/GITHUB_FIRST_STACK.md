# COMPUTER WISDOM — GitHub-First Evidence Stack v0.1

Status: DRAFT_BRANCH_POLICY. Owner: Jason Wisdom. No merge/deploy/publication authorization.

## Precedence (not blanket proof)
1. GitHub versioned source, immutable commits, CI results, and evidence receipts are the primary **project index and verification ledger**.
2. Google Drive stores original documents and archives; references require original file IDs, revision metadata and hashes where available.
3. ChatGPT retrieves, compares, tests and proposes; it is not the canonical evidence repository.
4. ChatGPT memory and past-chat summaries are discovery hints, never independent proof.

## Before answering UNKNOWN
- Identify the exact claim and verification scope.
- Search the GitHub project index, relevant commits and original receipts first.
- Follow document pointers to Drive and recoverable conversation records when permitted.
- Reuse prior PASS only for the exact tested claim; independently replay if stronger proof is requested.
- Report sources searched and unresolved gaps; distinguish NOT_SEARCHED from NOT_VERIFIED.
- Preserve prior receipt and note conflicts rather than overwriting.

## 700-thread migration boundary
Do not claim that 700 conversations have been ingested. Inventory only actually retrieved
threads; store pointers and hashes rather than confidential transcripts or secrets in a
public repository. Maintain an append-only migration manifest with source ID, project,
claim IDs, retrieval date, evidence links, scope, status and consent/access classification.
No inferred or fabricated missing records. Never upload private chats to public GitHub.
