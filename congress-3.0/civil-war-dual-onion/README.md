## Purpose

Use the U.S. Civil War and Reconstruction as a two-onion replay laboratory for learning how records, authority, consequences, constitutional change, and later memory can disagree without forcing false symmetry or modern tribal labels.

This is an educational replay game. It is not a modern conflict simulator, political enemy list, military command system, genealogy engine, or historical truth oracle.

## Dualistic Onion

### Onion A — Public record / human record

```text
EVENT / CLAIM
-> PRIMARY SOURCE
-> ARCHIVE / VERSION
-> DATE / PLACE
-> SPEAKER / WITNESS
-> HUMAN CONSEQUENCE
-> CONTRADICTORY RECORD IF ANY
-> RECEIPT
```

### Onion B — Authority / system

```text
CONSTITUTION
-> OFFICE / GOVERNMENT LEVEL
-> CLAIMED AUTHORITY
-> LAW / ORDER / PROCLAMATION / COURT ACTION
-> IMPLEMENTATION
-> MONEY / MILITARY / ADMINISTRATIVE ACTION IF RELEVANT
-> CONSEQUENCE
-> LATER AMENDMENT / PRECEDENT / SUPERSESSION
-> RECEIPT
```

The onions cross only through a bound receipt.

## Terminal states

`PASS | HOLD | CONFLICT | REJECT`

- `PASS` — the round's bounded claim and source/authority path reconcile.
- `HOLD` — evidence needed by the selected question is missing.
- `CONFLICT` — valid bound records disagree and the disagreement is preserved.
- `REJECT` — the proposed round claim contradicts the bound evidence or violates a game membrane.
