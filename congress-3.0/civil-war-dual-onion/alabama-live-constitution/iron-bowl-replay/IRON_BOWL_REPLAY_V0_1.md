# IronBowlReplay v0.1

**Parent:** Double Onion Civil War Alabama Live Constitution v0.1  
**Classification:** `RIVALRY_AS_CIVIC_REPLAY_MECHANIC`  
**Authority created:** `false`

## Purpose

Use Alabama–Auburn football rivalry as a familiar Alabama game surface for learning how to disagree, cross-check claims, preserve identity, and demand receipts without turning rivalry into historical allegiance, enemy status, or proof.

```text
ROLL_TIDE = GAME_PERSPECTIVE_LABEL
WAR_EAGLE = GAME_PERSPECTIVE_LABEL
TEAM_IDENTITY != HISTORICAL_ALLEGIANCE
TEAM_IDENTITY != POLITICAL_IDENTITY
TEAM_IDENTITY != MORAL_WORTH
```

## Replay loop

```text
PLAY / CLAIM
-> ROLL_TIDE OR WAR_EAGLE PERSPECTIVE
-> WHAT IS ACTUALLY BEING CLAIMED?
-> SOURCE
-> DATE / PLACE
-> RULE / AUTHORITY IF RELEVANT
-> RECEIPT
-> OPPOSING-PERSPECTIVE REPLAY
-> PASS | HOLD | CONFLICT | REJECT
```

## Iron Bowl translation layer

```text
RIVALRY -> DISAGREEMENT WITHOUT DEHUMANIZATION
CHEERING -> PERSPECTIVE, NOT EVIDENCE
SCOREBOARD -> GAME RESULT, NOT HISTORICAL TRUTH
TRADITION -> CULTURAL CONTEXT, NOT LEGAL AUTHORITY
REPLAY -> CHECK THE RECEIPT
REFEREE -> GAME ROLE, NOT COURT OR GOVERNMENT
```

## Double Onion crossing

### Onion A — Record

```text
CLAIM
-> SOURCE
-> EVENT
-> TIME / PLACE
-> OBSERVABLE RESULT
-> RECEIPT
```

### Onion B — Rule / Authority

```text
RULE OR CLAIMED AUTHORITY
-> WHO ISSUED IT?
-> WHAT TEXT?
-> WHAT VERSION?
-> WHAT ACTION FOLLOWED?
-> RECEIPT
```

A team preference never satisfies either onion.

## Core membranes

```text
BAMA_VS_AUBURN != NORTH_VS_SOUTH
IRON_BOWL != CIVIL_WAR
RIVAL != ENEMY
FAN != HISTORICAL_ACTOR
GAME_SCORE != HUMAN_WORTH

TRADITION != LAW

AUTHORITY_CREATED = FALSE
```

## Win condition

The player wins by producing the cleanest replayable receipt chain, not by making their side look perfect.

```text
BEST_RECEIPT_CHAIN > LOUDEST_TEAM_CLAIM
```
