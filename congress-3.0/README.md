## Purpose

Congress 3.0 extends the Congressional Accountability Membrane from record classification into end-to-end systems accountability.

It asks whether a government-facing system can prove the chain from legal authority to machine implementation, automated action, citizen consequence, review, and correction without silently converting technical capability into legal authority.

```text
LAW / AUTHORITY
  -> DELEGATED RULE
  -> MACHINE-READABLE RULE
  -> EXECUTION IDENTITY
  -> ACTION
  -> RECORD DELTA
  -> CITIZEN CONSEQUENCE
  -> NOTICE / EXPLANATION
  -> REVIEW
  -> CORRECTION / REMEDY
  -> REPLAY
```
